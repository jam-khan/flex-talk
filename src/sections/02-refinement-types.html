Refinement types

{ v : i32 | 0 <= v }

the i32 values v such that 0 <= v

Subtyping

{ v: i32 | 0 < v } <: { v: i32 | 0 <= v }
\(\forall v.\; 0 < v \Rightarrow 0 \le v\)

Example: foreach

fn foreach<F>(lo: usize, hi: usize, mut f: F)
where
    F: FnMut(usize{v: lo <= v && v < hi})
{
    let mut i = lo;
    whileinvariant: κ(i, hi, lo) i < hi {
        f(i);
        i += 1;
    }
}
Flux
\(\forall lo, hi.\) \(\kv(lo, hi, lo)\) \(\wedge\; \forall i.\) \(\kv(i, hi, lo)\) \(\Rightarrow\; i < hi \;\Rightarrow\) \(lo \le i \;\wedge\; i < hi\) \(\wedge\;\) \(\kv(i{+}1, hi, lo)\)
solution \(\kv(i, hi, lo)\) \(\;\triangleq\; lo \le i \le hi\)

Example: dot

fn dot(n: usize, x: &[f64][n], y: &[f64][n]) -> f64
{
    let mut res = 0.0;
    let body = |jusize{v: κ(v, n)}| {
        res += x[j] * y[j]
    };
    foreach(0, n, body);
    res
}
Flux
\(\forall n.\) \(\forall j.\;\) \(\kv(j, n)\) \(\Rightarrow\; j < n\) \(\wedge\) \(\forall v.\; (0 \le v \;\wedge\; v < n) \Rightarrow\) \(\kv(v, n)\)
solution \(\kv(j, n)\) \(\;\triangleq\; 0 \le j \;\wedge\; j < n\)
