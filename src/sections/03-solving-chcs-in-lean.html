strongest solution
\(\kv(z_0, z_1, z_2)\) \(\;\triangleq\; (z_0 = z_2) \;\vee\; (\) \(\kv(z_0{-}1, z_1, z_2)\) \(\;\wedge\; z_0{-}1 < z_1)\)

the definition refers to itself — zap would loop

Fix: start strong, then iterate

qualifiers (a.k.a. templates)
\(q_{\le}(a, b) \;\triangleq\; a \le b\) \(q_{<}(a, b) \;\triangleq\; a < b\) \(q_{=}(a, b) \;\triangleq\; a = b\)

\(\kv(z, hi, lo) \;\triangleq\; \bigwedge\)
