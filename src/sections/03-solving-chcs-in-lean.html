Cyclic vs. acyclic constraints

Predicate abstraction

qualifiers (a.k.a. templates)
\(q_{\le}(a, b) \;\triangleq\; a \le b\) \(q_{<}(a, b) \;\triangleq\; a < b\) \(q_{=}(a, b) \;\triangleq\; a = b\)
Qualifiers are Lean 4 predicates, tagged with @[qual]
@[qual] def q_le (a b : Int) : Prop := a ≤ b @[qual] def q_lt (a b : Int) : Prop := a < b @[qual] def q_eq (a b : Int) : Prop := a = b
generate all combinations
\(\kv(z, hi, lo) \;\triangleq\; \bigwedge\)
\(lo \le z\) \(z \le lo\) \(z \le hi\) \(hi \le z\) \(lo < z\) \(z < hi\) \(hi < z\) \(z = lo\) …

Start strong, then iteratively weaken it.

The mathematical templates above are the Lean predicates below, in the same order. The qual attribute registers a predicate as a qualifier. Fix instantiates these templates with well-typed combinations of the Horn variable's parameters, then weakens the conjunction until inductive. Qualifiers can use arbitrary Lean predicates, not just these comparisons.
